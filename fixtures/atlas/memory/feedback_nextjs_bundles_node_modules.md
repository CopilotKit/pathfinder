**Rule:** When hyperlocal-patching a Next.js container to test a fix in any npm dependency, patch BOTH:
1. `/path/to/app/node_modules/<package>/...` (source-of-truth for compile but NOT what runs)
2. `/path/to/app/.next/server/chunks/*.js` (the actual bundled code Next.js executes)

**Why:** Earned during D5 header-forwarding hunt. The runtime loads from the chunk, not from node_modules. Patching node_modules had zero effect on the running code.

**How to apply:** After identifying the file/function to patch in `node_modules/<package>/dist/`, ALSO grep for the function in `/app/.next/server/chunks/*.js` and patch both before restart.
